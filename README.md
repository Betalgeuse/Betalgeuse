# Sanghyuk Lee

I turn unmeasured uncertainty into measured risk, so decisions rest on evidence instead of fear of missing out.

Crop science at Seoul National University (with entrepreneurship), now building agent systems and honest, reproducible analysis for insurance and risk.

## Selected work

- **[crop-risk](https://github.com/Betalgeuse/crop-risk).** Korean crop disaster insurance loss ratios reproduced from public data only. 2012–2024 payouts were 99.3% of the risk premium, yet 2012 alone hit 357%, and crops are priced unevenly against each other. A rebuild from the raw files is byte-identical.
- **octo** (private). A one-person operating system where agents take work from issue to PR, verification and merge. State rules are checked with TLA+ models and gates, not by a person reading logs.
- **V-Contents at Vibers AI.** Product-image generation for K-beauty brands: a multi-step Gemini chain, Seedream, background removal and OpenCV text placement on an editable canvas. I wrote 209 of the repository's 289 commits (2025-09 to 2025-10).
- **[OT1L](https://github.com/Betalgeuse/ot1l).** A Slack community bot for daily "one thing" goals and retrospectives, run by agents with operator review.
